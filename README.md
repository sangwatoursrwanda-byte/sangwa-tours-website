# SANGWA Tours Website

A responsive multi-page Rwanda tour operator website with English, French and Kinyarwanda language switching and WhatsApp booking enquiries.

## Files
- `index.html` — homepage
- `about.html` — about SANGWA Tours
- `tours.html` — tour ideas
- `destinations.html` — Rwanda destinations
- `gallery.html` — image gallery
- `contact.html` — contact and WhatsApp booking enquiry form
- `style.css` — styling and responsive layout
- `script.js` — language switching and WhatsApp enquiry behaviour
- `images/` — local SVG illustrations used by the website

## Preview locally
Open `index.html` in a web browser. All pages are linked together.

## Publish free with GitHub Pages
1. Open your GitHub repository: `sangwa-tours-website`.
2. Choose **Add file → Upload files**.
3. Extract this ZIP on your computer first.
4. Upload all files and folders inside `sangwa-tours-website` (not the outer ZIP).
5. Commit the changes to the `main` branch.
6. Open **Settings → Pages**.
7. Under **Build and deployment**, choose **Deploy from a branch**.
8. Choose branch `main` and folder `/ (root)`, then click **Save**.
9. Wait a few minutes. GitHub will show your website address in the Pages section.

## Contact number
The WhatsApp and phone links are set to **+250 793 193 594**. To change it later, search for `250793193594` in `contact.html` and `script.js`, and replace it with your new number (digits only).

## Important
- This website sends booking enquiries to WhatsApp. It does not process card/mobile-money payments or store bookings in a database.
- Tour prices are not invented; customers are asked to request a quotation.
- Replace the sample SVG illustrations in `images/` with your own licensed photographs when ready.
- Google Fonts are used when internet access is available; the website still works with fallback fonts.
